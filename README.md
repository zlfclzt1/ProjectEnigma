# 艾泽拉斯公会志

> 重返经典旧世，书写属于你的公会远征史。

《艾泽拉斯公会志》是一款正在开发中的单机放置公会经营游戏。招募成员、组织远征、挑战熟悉的副本，并决定每一件战利品的归属。

**[下载 macOS Alpha v0.1.0-alpha.1](https://github.com/zlfclzt1/ProjectEnigma/releases/tag/v0.1.0-alpha.1)**

适用于 Apple Silicon（M1 或更新芯片）与 macOS 13.3 以上系统。

## macOS 安装

1. 下载并打开 `.dmg`，将《艾泽拉斯公会志》拖入“应用程序”。
2. 首次启动时，系统会提示应用来自身份不明的开发者。这是因为当前 Alpha 尚未签名和公证。
3. 在 Finder 的“应用程序”中按住 Control 点击应用，选择“打开”；如果仍被拦截，请前往“系统设置 → 隐私与安全性”，点击“仍要打开”。
4. 应用会常驻菜单栏，并自动在默认浏览器中打开游戏。退出游戏请使用菜单栏中的“退出”。

游戏存档由桌面应用保管，不依赖浏览器缓存。菜单栏可以重新打开游戏、查看存档位置或归档当前存档后重新开始。

## 核心循环

**招募成员 → 组织队伍 → 派遣远征 → 处理战利品 → 壮大公会**

### 经营属于你的艾泽拉斯公会

从一支五人小队起步，招募不同职业、专精与性格的成员。培养新人，调整阵容，同时管理多支远征队，让公会成员规模从五人逐步扩展至三十人。

### 重走原汁原味的经典副本

从怒焰裂谷、死亡矿井与影牙城堡，一路远征至玛拉顿、阿塔哈卡神庙和黑石深渊。选择副本路线与可选 Boss，并在出发前评估每场战斗的胜率、全通率和预计耗时。

### 决定每一件战利品的归属

查看装备的真实属性、需求和掉落来源，比较它对不同成员的提升。手动分配关键装备，审核自动处理方案，并逐步完成公会的装备图鉴与收藏记录。

## 当前版本

完整版本变化请查看[更新日志](CHANGELOG.md)。

- 19 座可重复挑战的经典副本，共 144 场路线遭遇。
- 完整的 10–60 级成长路线，当前远征终点为黑石深渊的达格兰·索瑞森大帝。
- 九大职业、固定专精、六种性格，以及低概率出现的隐藏角色。
- 多队并行远征，支持必打、主动选择的可选 Boss 与途中揭晓的随机稀有 Boss。
- 真实装备属性、随机词缀、成员副本任务、装备图鉴与收藏奖励。
- 结构化战报记录伤害、治疗、承伤、奖励和远征日志。
- 单机运行，无需注册账号或连接游戏服务器。

## 从源码运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```bash
npm install
npm run dev
```

在浏览器中访问 `http://localhost:4173/`。

如果你想了解构建、测试、内容校验和项目架构，请查看[开发者文档](DEVELOPMENT.md)。

## 开发状态

项目目前处于 Alpha 阶段，但 10–60 级公会成长、多队远征、战利品分配与副本收藏已经形成完整可玩循环。当前已开放 27 座经典副本，内容终点推进至上层黑石塔的达基萨斯将军；完成前置七本首通后可组织推荐 2 坦、2 治疗、6 输出的十人远征。
