# 神秘公会：放置公会会长原型

一个无需安装第三方依赖的浏览器放置游戏原型。当前开放怒焰裂谷、死亡矿井、哀嚎洞穴和影牙城堡，验证招募、培养、组队、副本计时、离线结算和装备分配的核心循环。

## 运行

```bash
npm run serve
```

然后访问：

```text
http://localhost:4173/
```

开发调试模式：

```text
http://localhost:4173/?debug=1
```

调试模式会提供“立即完成下一阶段”和“重置存档”按钮。普通模式严格使用副本真实计时。

## 测试

```bash
npm test
npm run simulate:rfc
```

## 已实现

- 开局完整五人队，保证 1 坦克、1 治疗、3 输出
- 九职业、跨阵营种族组合和固定专精
- 成员页与副本组队页的职业、定位组合筛选
- 六种具有优缺点的性格
- 三名初始候选人、30 分钟自然招募和付费生成
- 四座可选择副本，共 27 个 Boss 路线节点
- 前置副本与公会成员等级共同决定永久解锁；解锁后允许带低级成员
- 精确 Boss 通过率、全通率和预计耗时
- 非标准阵容与最低 50% 副本时间
- 出发时锁定成功、掉落与日志随机结果
- 多队并行和最多三次连续挑战
- Boss 分段经验、资金和掉落
- 灭团保留已经取得的奖励
- 关闭页面后的离线结算
- 经典角色面板式完整装备栏、数据库装备图标、物品提示和综合装等
- 参战资格、装备限制、绑定和旧装备自动出售
- 手动及自动战利品分配
- 转专精和不适配装备处理
- 俏皮战斗日志
- 浏览器本地存档
- 倒计时局部刷新，不打断下拉选择和成员管理面板

## 当前原型边界

- 当前开放怒焰裂谷、死亡矿井、哀嚎洞穴和影牙城堡。
- 奥格弗林特和巴扎兰使用怒焰裂谷任务奖励组成的共享装备池，以兼容“每个 Boss 必掉一件装备”的规则。
- 三座新增副本的每个 Boss 已录入至少一件真实装备；后续仍需扩充完整掉落池和原始属性。
- 公会扩建条件已经写入设计文档，尚未接入页面。
- 其余 20–45 级副本、完整物品库和 60 级内容尚未导入。
- 当前存档保存在浏览器本地存储，不包含账号或云同步。

## 项目结构

```text
data/       副本和掉落内容数据
docs/       总设计与垂直切片规格
scripts/    数值模拟脚本
src/        浏览器界面、状态机和战斗核心
tests/      核心规则与离线结算测试
```
