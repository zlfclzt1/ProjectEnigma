# 45–60 级黑石塔阶段实施计划

- 文档状态：执行中
- 最后更新：2026-09-09
- 关联设计：[游戏设计文档 v0.2](./game-design-v0.1.md)
- 前置阶段：[10–45 级祖尔法拉克阶段实施计划](./zulfarrak-stage-implementation-plan.md)
- 内容政策：[经典旧世内容版本与来源政策](./classic-content-source-policy.md)
- 内容流程：[新增经典旧世副本工作流](./adding-dungeon-workflow.md)

本文档承接已经完成的祖尔法拉克阶段，把 45–60 级升级、满级五人本和第一轮团本前装备准备拆成可以独立验证和提交的小任务。阶段主线终点为首次击败上层黑石塔的达基萨斯将军；首通后继续刷五人本、收集套装和培养替补。

本阶段继续坚持：只有玩家主动安排的活动才产生离线收益。不会因为解锁 60 级而加入后台自动刷本、被动金币或离线自动分装。

## 1. 阶段交付目标

- 祖尔法拉克首通后把成员等级上限从 45 解锁到 60，已经领取旧里程碑的存档自动生效。
- 保留现有十五座副本和全部 10–45 级玩法，不重置成员、装备、图鉴、任务或首杀记录。
- 新增十二个可重复挑战的副本定义：
  - 玛拉顿
  - 阿塔哈卡神庙
  - 黑石深渊：禁闭区
  - 黑石深渊：暗炉城
  - 黑石塔下层
  - 黑石塔上层
  - 厄运之槌：东区
  - 厄运之槌：西区
  - 厄运之槌：北区
  - 通灵学院
  - 斯坦索姆：血色区
  - 斯坦索姆：亡灵区
- 完整录入主要 Boss 的非世界专属装备、重要成员任务奖励和真实随机词缀。
- 用现有必打、普通可选和随机稀有节点表达完整主路线；大体量实例通过有明确边界的分区定义控制单次活动长度。
- 黑石塔上层验证 10 人队伍、名单筛选、活动快照、掉落资格和战报布局，不重写五人本调度器。
- 录入经典 Dungeon Set 1 的真实部件和掉落来源，替换当前仅用于验证通用能力的套装原型。
- 建立从祖尔法拉克毕业存档到达基萨斯首通的固定种子进度基线。
- 首次击败达基萨斯将军后自动记录“60 级团队副本准备就绪”，游戏继续运行。

## 2. 内容切分决定

### 2.1 为什么拆分大型实例

血色修道院已经证明“同一实例的独立区域作为不同副本定义”能够保持路线清晰。45–60 级阶段沿用同一原则：

- 黑石深渊拆为禁闭区和暗炉城，避免一次活动塞入过多必打与可选节点。
- 厄运之槌按东、西、北三个正式区域拆分。
- 斯坦索姆按血色区和亡灵区拆分。
- 黑石塔下层与上层分别建模；上层是本阶段唯一推荐 10 人的副本。
- 玛拉顿和阿塔哈卡神庙保留单一副本定义，通过普通可选节点表达分支。

拆分只改变放置游戏的活动边界，不把同一件装备复制为多个定义。装备图鉴仍允许同一基础物品显示多个真实来源。

### 2.2 阶段主线

阶段解锁采用公会级永久里程碑，不建立钥匙背包或逐成员入场资格：

```text
祖尔法拉克首通
  → 解锁 60 级上限与玛拉顿
  → 阿塔哈卡神庙
  → 黑石深渊：禁闭区
  → 黑石深渊：暗炉城
  → 黑石塔下层
  → 黑石塔上层
  → 达基萨斯将军首通
```

厄运之槌、通灵学院和斯坦索姆在 55–60 级区间形成并行装备路线，不作为黑石塔上层的全部硬前置。玩家可以选择不同路线补齐套装和职责装备。

### 2.3 暂不进入本阶段

- 熔火之心及其他团队副本。
- 团本进度锁、每周重置和团队副本装备分配制度。
- 专业、材料、公会仓库、拍卖行和消耗品准备。
- 世界掉落、普通怪随机绿装和完整区域任务链。
- 钥匙物品背包、门锁点击、逐成员副本门票和阵营限制。
- 厄运之槌贡品路线的通用路线编辑器；若完整内容确实需要，只实现一个内容驱动的命名路线变体，不扩展成自由路线编辑。
- Tier 0.5 升级任务链、团队套装和套装战斗特效。
- Boss 定向速刷、无玩家安排的循环队列和自动重复开团。

## 3. 资料口径

继续采用 `classic-2019-phase-6`：

- [Wowhead Classic 副本总览](https://www.wowhead.com/classic/guide/classic-dungeons-overview)：确认经典旧世副本名单和等级段。
- [AtlasLootClassic DungeonsAndRaids 数据](https://github.com/Hoizame/AtlasLootClassic/blob/master/AtlasLootClassic_DungeonsAndRaids/data.lua)：确认 Boss、分区、装备 ID 和套装来源。
- Wowhead Classic 物品 XML：逐件核对名称、物品等级、需求等级、属性和图标。
- Warcraft Wiki Classic 与 Wowhead Classic 单副本攻略：交叉核对路线、必打、可选、稀有和事件 Boss。

每座副本继续先提交 `docs/dungeon-research/<dungeon-id>.md`，再录入内容。调查文档必须明确排除世界掉落、任务物品、材料、配方和没有培养价值的普通怪掉落。

## 4. 数值目标

### 4.1 进度节奏

固定种子模拟从“祖尔法拉克已首通、核心五人 45 级”的合法存档开始：

- 每天主动管理 4–6 次时，达基萨斯首通中位目标为 10–14 天。
- 每天主动管理 3 次的低频压力场景，P90 目标不超过 24 天。
- 不要求全公会成员达到 60 级，也不要求集齐 Dungeon Set 1。
- 不依赖付费刷新、隐藏角色或单一稀有掉落才能首通。
- 模拟必须包含正常招募、至少一次速带、五次连续挑战、成员任务、普通可选 Boss、随机稀有 Boss、手动和自动分装。

### 4.2 60 级副本平衡

- 推荐等级标准队主路线全通率继续以约 79%–84% 为初始目标。
- 满级团本前合理装备队可以稳定重复刷本，但一般 Boss 仍保留非零失败风险。
- 10 人上层黑石塔按推荐 10 人校准；五人挑战允许出发，但应明确显示职责和总战力不足。
- 高等级回刷低级本不减少掉落，仍受每座副本的最短耗时下限约束。
- 60 级停止获得经验并清空溢出经验。

## 5. 执行与提交规则

- 继续一个编号任务一个 commit。
- 每个中间提交保持旧存档、十五座旧副本和祖尔法拉克阶段门禁通过。
- 通用能力、内容调查、内容录入、平衡和发布 E2E 不混在同一提交。
- 不在单副本任务中修改全局经验曲线或通用战斗公式。
- `vite.config.ts` 等用户已有无关修改不得进入任务提交。

### 任务 0.2：集中管理可解锁等级上限

状态：已完成。等级上限、经验结算和 UI 预览已统一，祖尔法拉克毕业记录解锁 60 级。

目标：消除经验结算、任务奖励和 UI 中分散的 `45` 硬编码，当前行为仍保持 45 级封顶。

实现：

- 增加统一的当前等级上限查询。
- 副本经验预览、逐 Boss 经验结算、任务经验和 UI 使用同一结果。
- 祖尔法拉克里程碑提供 `level_cap_60` 管理解锁；已领取该奖励的旧存档自动获得效果。
- 在第一座 45–60 副本加入前，未取得里程碑的公会仍停在 45 级。

测试：

- 未首通祖尔法拉克时保持 45 级封顶。
- 首通后上限变为 60，45 级溢出经验仍不从旧结算追溯补发。
- 60 级不保存溢出经验。
- 已领取旧奖励的存档加载后立即识别新管理效果。

建议 commit：

```text
feat: unlock the level 60 progression cap
```

### 任务 0.3：建立后祖尔法拉克进度模拟骨架

状态：已完成。独立 schema v1 基线会从合法毕业存档主动安排旧副本，验证带新人、刷装和经验增长，并在现有 45 级内容经验耗尽后明确返回 `content-cap`。

新增独立 schema v1 基线，从合法的 45 级阶段毕业存档开始，不覆盖现有 10–45 级基线。

首版只验证：

- 旧十五座副本可以继续刷装和带新人。
- 等级上限解锁后经验可以继续增长到 60。
- 当前没有 45 级以上副本时明确返回 `content-cap`，不伪造达基萨斯完成时间。
- 所有收益仍来自模拟器主动安排的活动。

当前边界说明：等级系统已经允许成员升到 60，但旧副本在成员高于推荐等级 8 级后不再提供经验，因此仅有推荐等级 45 的现有内容会在核心成员约 53 级时触及内容上限。基线不会为了得到虚假的 60 级结果修改经验规则，也不会记录不存在的达基萨斯首通日期。

建议 commit：

```text
test: add post-zulfarrak progression baseline
```

阶段 0 门禁：完整旧阶段门禁通过，当前玩家体验除祖尔法拉克首通后可继续升级外不发生变化。

## 7. 阶段 1：满级内容通用能力

### 任务 1.1：验证 6–10 人队伍通用链路

状态：已完成。使用测试副本验证内容定义的 10 人上限，十名成员可完整进入活动快照、占用状态、逐 Boss 战报与掉落候选；界面可从更大名单中筛选、排序并选满十人，活动卡和可横向滚动的战报表格继续复用现有响应式布局。

先用测试内容验证：

- 组队筛选、排序和人数上限支持 10 人。
- 活动快照、成员占用、逐 Boss 结算和掉落资格保存 10 人名单。
- 战报表格、活动卡和战利品候选在窄屏下仍可用。
- 不修改五人副本现有结果。

建议 commit：

```text
test: verify ten-player expedition support
```

### 任务 1.2：支持内容驱动的命名路线变体

只为确有原版意义的路线增加最小能力：

- 一个副本可以声明少量命名路线变体。
- 玩家出发前选择一个变体，活动快照保存稳定 ID。
- 变体决定必打和不可同时出现的节点，普通可选与随机稀有仍复用现有规则。
- 首版用于厄运之槌北区普通路线与贡品路线，不提供自由拖拽路线编辑。

建议 commit：

```text
feat: support named dungeon route variants
```

### 任务 1.3：扩展正式套装与多来源图鉴测试

- 用真实 Dungeon Set 1 结构替换套装原型。
- 验证同一部件可在图鉴中展示准确来源，基础物品只计一次收藏。
- 套装进度不要求获得所有随机词缀。
- 第一阶段只做收藏和分装价值，不实现套装战斗特效。

建议 commit：

```text
feat: prepare authentic dungeon set collections
```

## 9. 阶段 3：黑石深渊双分区

### D18：黑石深渊禁闭区

- 覆盖入口、监牢、竞技场及该活动边界内的主要 Boss。
- 任务链压缩为可由实例内胜利或分区全通确定的成员任务。
- 不建立钥匙背包；门与捷径使用公会首通里程碑表达。

## 13. 阶段 7：60 级装备生态

### 任务 7.1：完成 Dungeon Set 1

- 九职业套装部件、真实 Boss 来源和图鉴进度完整。

- 手动分配永远可用，不加入核心成员优先级或 DKP。

### 任务 7.3：完成装备与来源总审计

- 所有主要 Boss 的非世界专属装备均有正确来源。
- 无专属装备池的 Boss 保持零装备掉落。
- 任务奖励、世界掉落和 Boss 池无重复。
- 所有真实装备属性和图标来源完整。

## 14. 阶段 8：平衡、里程碑与发布

### 任务 8.1：校准 45–60 级经验与耗时

- 保持现有速带衰减和碾压耗时下限原则。
- 校准 45–60 级副本经验，使玩家不需要在单一副本无限刷级。
- 60 级严格封顶，不保存溢出经验。

### 任务 8.2：校准达基萨斯进度基线

- 每天主动管理 4、5、6 次。
- 正常招募、速带、任务、可选/稀有路线、五连和两种分装方式。
- 中位与 P90 满足第 4 节目标。
- 不依赖隐藏角色、付费刷新或异常阵容。

### 任务 8.3：增加 60 级阶段里程碑

首次击败达基萨斯将军自动领取：

```text
名称：60 级团队副本准备就绪
效果：一次性公会资金 + 展示记录
```

首通后所有五人本、招募、任务、图鉴和分装继续运行；不自动进入熔火之心，也不关闭经验以外的玩法。

### 任务 8.4：完整阶段 E2E

至少覆盖：

```text
读取祖尔法拉克毕业存档
→ 解锁 60 级上限
→ 玛拉顿继续升级

→ 离线结算
→ 手动与自动分装
→ 更新 Dungeon Set 1
→ 首通达基萨斯
→ 刷新后继续游玩
```

## 15. 最终发布门禁
